## Só para o Claude Code

- Sessão nova num projeto em andamento: se existir `.escritorio/estado.md`, use a skill escritorio:passagem no modo retomar antes de começar.
- Tarefa grande ou com várias partes: comece no modo de planejamento e mostre o plano antes de editar.
- Quando o gatilho do escritório pedir, rode a skill escritorio:pente-fino antes de encerrar.
- "sem pente-fino" pula a revisão daquele pedido; "desliga o pente-fino" pausa na sessão; "liga o pente-fino" volta.
- Tarefa mecânica que mexe em muitos arquivos (renomear, trocar import, padronizar formatação): delegue ao subagente ajudante-rapido, se ele estiver instalado.
